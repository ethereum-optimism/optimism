---
title: How to rewind op-geth
description: Learn how to rewind an op-geth node to a previous chain head.
---

<Warning>
  **This procedure applies only to op-geth, which reached end-of-support on 2026-05-31 and will not support the L1 Glamsterdam hardfork.** See the [op-geth deprecation notice](/notices/op-geth-deprecation).

  The `op-wheel engine rewind` steps below target op-geth's engine API. **Do not run them against an op-reth node** — state rewind on op-reth follows a different procedure, and using the op-geth flow can leave your datadir in an inconsistent state.

  An op-reth rewind tutorial is in progress. If you need to rewind an op-reth node now, [open an issue](https://github.com/ethereum-optimism/docs/issues) or reach out to support.
</Warning>
