title: Adding a precompile
description: Learn how to run an EVM with a new precompile for OP Stack chain operations to speed up calculations that are not currently supported.
---

<Warning>
  **This tutorial patches op-geth source directly (`op-geth/core/vm/contracts.go`), and op-geth reached end-of-support on 2026-05-31.** It does not apply to op-reth, the default OP Stack execution client. See the [op-geth deprecation notice](/notices/op-geth-deprecation).

  Adding a precompile remains an unsupported OP Stack Hack regardless of client, and following these op-geth-specific steps on an op-reth node will not work.

  An op-reth precompile walkthrough is in progress. If this is a use case you need, [open an issue](https://github.com/ethereum-optimism/docs/issues) describing it.
</Warning>
