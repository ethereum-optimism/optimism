ZK proofs are how OP Stack chains secure withdrawals without a trusted third party. Anyone can propose the state of the chain on Ethereum, and anyone can challenge a proposal they believe is wrong. A challenged proposal stands only if someone proves it with a zero-knowledge proof before its deadline, and the proof is verified on Ethereum in a single call.

This page is the recommended reading order for the topic. Start with the explainer for the mental model, then read the pages on the game and the proof system to see how the pieces fit. Use the operator guides if you run a chain, and the spec for full depth.
