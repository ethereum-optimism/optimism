# Optimism Docs

이 디렉터리에는 [docs.optimism.io](https://docs.optimism.io/)에 게시되는 Optimism Docs가 포함되어 있습니다. 문서와 관련된 모든 업데이트와 새 콘텐츠는 [`ethereum-optimism/optimism`](https://github.com/ethereum-optimism/optimism) 모노레포 내의 이곳에서 추적 및 관리됩니다.

## 로컬 개발

모노레포 루트에서 `just public-docs`를 실행한 뒤 [localhost:3000](http://localhost:3000)에 접속하십시오. [mise](https://mise.jdx.dev)를 설치하고 `mise install bun just`를 실행해 두기만 하면 됩니다. 자세한 내용은 [DOCS_CONTRIBUTING.md](DOCS_CONTRIBUTING.md#개발-환경-설정)를 참고하십시오.
