`kona-node`는 L2 합의 클라이언트이므로 디스크에 거의 아무것도 저장하지 않습니다!

<Note>
디스크에 저장되는 모든 항목은 구성할 수 있으며, 비활성화할 수 있습니다.
</Note>

rollup node로서 `kona-node`는 항상 L2 블록을 실행 클라이언트
(`op-reth` 또는 `op-geth`)로 보내 실행합니다. 따라서 체인 상태는 전적으로
실행 클라이언트가 처리합니다. 이러한 방식 덕분에 `kona-node`는 매우
가벼우며 다양한 하드웨어에서 실행할 수 있습니다.

다만 노드의 P2P(peer-to-peer) 부분에는 안정적이고 신뢰할 수 있는 인터넷
연결이 매우 중요합니다. `kona-node`는 unsafe 체인을 동기화하기 위해 P2P
통신에 의존합니다. 연결이 불안정하면 노드가 따라잡는 데 어려움을 겪을 수
있으며, 너무 느리다는 이유로 피어에게 차단될 수 있습니다.
