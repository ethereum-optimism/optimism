`optimism` API는 Kona의 rollup 상태 및 구성과 상호작용하기 위한 메서드를 제공합니다.

## `optimism_outputAtBlock`

특정 블록 번호의 output root를 반환합니다. 여기에는 L2 블록 참조, 출금(withdrawal) storage root, state root, 동기화 상태가 포함됩니다.

| 클라이언트 | 메서드 호출                                              |
| ------ | -------------------------------------------------------------- |
| RPC    | `{"method": "optimism_outputAtBlock", "params": [blockNumber]}` |

### 매개변수

- `blockNumber` (`BlockNumberOrTag`): output을 가져올 블록 번호입니다. 숫자, "latest", "earliest", "pending", "safe", "finalized" 중 하나를 사용할 수 있습니다.

### 반환값

`OutputResponse` - 다음을 포함하는 객체:
- `version` (`string`): output 버전 해시
- `outputRoot` (`string`): output root 해시
- `blockRef` (`L2BlockInfo`): L2 블록 참조
- `withdrawalStorageRoot` (`string`): 출금 storage root
- `stateRoot` (`string`): state root
- `syncStatus` (`SyncStatus`): 노드의 현재 동기화 상태

## `optimism_syncStatus`

L1 및 L2 블록 상태 정보를 포함하여 rollup node의 현재 동기화 상태를 반환합니다.

| 클라이언트 | 메서드 호출                            |
| ------ | -------------------------------------------- |
| RPC    | `{"method": "optimism_syncStatus", "params": []}` |

### 반환값

`SyncStatus` - 상세한 동기화 정보를 포함하는 객체:
- `current_l1` (`BlockInfo`): derivation이 현재 대기 중인 L1 블록
- `current_l1_finalized` (`BlockInfo`): 현재 최종 확정된 L1 블록(레거시/지원 중단됨)
- `head_l1` (`BlockInfo`): L1 head 블록 참조
- `safe_l1` (`BlockInfo`): L1 safe head 블록 참조
- `finalized_l1` (`BlockInfo`): 최종 확정된 L1 블록 참조
- `unsafe_l2` (`L2BlockInfo`): unsafe L2 블록 참조(절대적 최신 블록)
- `safe_l2` (`L2BlockInfo`): safe L2 블록 참조(L1에서 derive됨)
- `finalized_l2` (`L2BlockInfo`): 최종 확정된 L2 블록 참조
- `local_safe_l2` (`L2BlockInfo`): L1에서 derive되었지만 아직 교차 검증되지 않은 로컬 safe L2 블록

## `optimism_rollupConfig`

rollup 체인의 동작과 속성을 정의하는 rollup 구성 매개변수를 반환합니다.

| 클라이언트 | 메서드 호출                              |
| ------ | ---------------------------------------------- |
| RPC    | `{"method": "optimism_rollupConfig", "params": []}` |

### 반환값

`RollupConfig` - 전체 rollup 구성을 포함하는 객체:
- `genesis` (`ChainGenesis`): rollup의 제네시스 상태
- `blockTime` (`number`): 초 단위의 L2 블록 시간
- `maxSequencerDrift` (`number`): 초 단위의 최대 sequencer drift
- `seqWindowSize` (`number`): sequencer window 크기
- `channelTimeout` (`number`): 채널 열림과 닫힘 사이의 L1 블록 수
- `graniteChannelTimeout` (`number`): Granite 하드포크 이후의 채널 타임아웃
- `l1ChainId` (`number`): L1 체인 ID
- `l2ChainId` (`number`): L2 체인 ID
- `batchInboxAddress` (`string`): 배치가 전송되는 L1 주소
- `depositContractAddress` (`string`): 입금(디파짓)용 L1 주소
- `l1SystemConfigAddress` (`string`): 시스템 구성용 L1 주소
- `protocolVersionsAddress` (`string`): 프로토콜 버전용 L1 주소
- 하드포크, 수수료, 상호운용성(interoperability)을 위한 추가 구성 필드

## `optimism_version`

Kona rollup node의 소프트웨어 버전을 반환합니다.

| 클라이언트 | 메서드 호출                        |
| ------ | ---------------------------------------- |
| RPC    | `{"method": "optimism_version", "params": []}` |

### 반환값

`string` - Kona 소프트웨어의 버전 문자열(예: "0.1.0")

### 예시

```js
// > {"jsonrpc":"2.0","id":1,"method":"optimism_version","params":[]}
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": "0.1.0"
}
```
