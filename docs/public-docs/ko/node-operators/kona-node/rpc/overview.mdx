`kona-node`는 노드와 상호작용하기 위한 JSON-RPC를 지원합니다.

기본적으로 `kona-node`는 동일한 수신 주소와 포트에서 HTTP와 WebSocket을 통해
JSON-RPC를 노출합니다. 등록된 모든 메서드는 두 전송 방식 모두에서
사용할 수 있습니다. IPC 전송은 지원되지 않습니다.

### 네임스페이스

JSON-RPC 메서드는 네임스페이스로 그룹화되며, 목록은 다음과 같습니다.

| 네임스페이스                    | 설명                                                                                            | 민감 여부 |
| ---------------------------- | ------------------------------------------------------------------------------------------------------ | --------- |
| [`p2p`](/ko/node-operators/kona-node/rpc/p2p)        | `p2p` API를 사용하면 p2p 스택을 구성할 수 있습니다.                                                   | 경우에 따라     |
| [`rollup`](/ko/node-operators/kona-node/rpc/rollup)  | `rollup` API는 OP Stack 전용 RPC 메서드를 제공합니다.                                               | 아니요        |
| [`admin`](/ko/node-operators/kona-node/rpc/admin)    | `admin` API를 사용하면 노드를 구성할 수 있습니다.                                                     | **예**   |


### RPC와 상호작용하기

Kona는 이러한 RPC 메서드를 기본적으로 활성화합니다.

`curl`, `httpie` 또는 원하는 프로그래밍 언어로 작성한 사용자 지정 클라이언트 등 모든 JSON-RPC 클라이언트를 사용해 RPC와 상호작용할 수 있습니다.
