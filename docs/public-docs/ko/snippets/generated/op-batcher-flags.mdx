| `--txmgr.rebroadcast-interval` | 게시된 트랜잭션이 아직 채굴되지 않은 경우 다시 브로드캐스트하는 간격입니다. 효과를 보려면 ResubmissionTimeout보다 작아야 합니다. | `12s` | `OP_BATCHER_TXMGR_REBROADCAST_INTERVAL` |
| `--txmgr.receipt-query-interval` | receipt를 폴링하는 주기 | `12s` | `OP_BATCHER_TXMGR_RECEIPT_QUERY_INTERVAL` |
| `--txmgr.retry-interval` | 일시적인 오류 발생 시 L1에 트랜잭션을 재제출하기 전에 대기할 시간입니다. 값이 \<= 0이면 즉시 재시도합니다. 효과를 보려면 ResubmissionTimeout보다 작아야 합니다. | `1s` | `OP_BATCHER_TXMGR_RETRY_INTERVAL` |
| `--txmgr.send-timeout` | 트랜잭션 전송 타임아웃입니다. 0이면 비활성화됩니다. | `0s` | `OP_BATCHER_TXMGR_TX_SEND_TIMEOUT` |
| `--wait-node-sync` | 시작 시 batcher가 L1의 최근 batcher tx가 (추가 블록 확인을 통해) 최종 확정될 때까지 대기할지 여부를 지정합니다. 중복 batcher tx를 방지하는 데 도움이 됩니다. | `false` | `OP_BATCHER_WAIT_NODE_SYNC` |
