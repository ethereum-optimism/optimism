### L1 시작 블록

| JSON 키 | 타입 | 설명 |
| --- | --- | --- |
| `l1StartingBlockTag` | L1 블록 번호, 태그 또는 해시 | L1StartingBlockTag는 L2를 특정 L1 블록에 고정(anchor)합니다. l1StartingBlockTag가 참조하는 블록의 타임스탬프는 L2 제네시스 블록, rollup-config, L1 output-oracle 컨트랙트에서 사용됩니다. L2 시작 타임스탬프가 nil인 경우, L2 제네시스가 이 값으로 설정되었다는 가정하에 Output oracle 배포 스크립트가 이 값을 사용할 수 있습니다. L2 제네시스 타임스탬프는 초기 L2 계정 상태에 영향을 주지 않습니다. Solidity 스크립트를 통한 L2 제네시스 allocs 생성 방식이 도입된 이후로 제네시스 시점의 L1Block 컨트랙트 스토리지는 0으로 초기화되기 때문입니다. |

### 결함 증명

FaultProofDeployConfig는 L1에 대한 결함 증명(fault proof) 배포를 설정합니다.

| JSON 키 | 타입 | 설명 |
| --- | --- | --- |
| `useFaultProofs` | boolean | UseFaultProofs는 시스템이 기존 output oracle 메커니즘 대신 결함 증명을 사용하는지 여부를 나타내는 플래그입니다. |
| `faultGameAbsolutePrestate` | 32-byte hash | FaultGameAbsolutePrestate는 Cannon의 절대 prestate입니다. 0번째에서 1번째 명령어까지의 증명을 생성하고 출력 JSON에서 prestate를 가져와 계산합니다. 모든 정직한 challenger는 프로그램의 설정 상태에 합의해야 합니다. |
| `faultGameMaxDepth` | number | FaultGameMaxDepth는 결함 분쟁 게임(fault dispute game) 내 position tree의 최대 깊이입니다. `2^{FaultGameMaxDepth}`는 실행 트레이스 이분법(bisection) 게임이 지원하는 명령어 수입니다. 전체 Cannon 트레이스를 위한 공간이 항상 충분하도록 보수적으로 설정하는 것이 이상적입니다. |
| `faultGameClockExtension` | number | FaultGameClockExtension은 claim 생성 시점에 남은 시간이 이 값보다 적은 경우, 분쟁 게임이 잠재적인 손자(grandchild) claim의 clock을 설정하는 시간입니다. |
| `faultGameMaxClockDuration` | number | FaultGameMaxClockDuration은 한 팀의 체스 clock에 누적될 수 있는 최대 시간이며, 이를 초과하면 더 이상 응답할 수 없습니다. |
| `faultGameGenesisBlock` | number | FaultGameGenesisBlock은 제네시스의 블록 번호입니다. |
| `faultGameGenesisOutputRoot` | 32-byte hash | FaultGameGenesisOutputRoot는 제네시스 블록의 output root입니다. |
| `faultGameSplitDepth` | number | FaultGameSplitDepth는 결함 분쟁 게임이 output root에서 실행 트레이스 claim으로 분할되는 깊이입니다. |
| `faultGameWithdrawalDelay` | number | FaultGameWithdrawalDelay는 사용자가 fault game에서 ETH를 출금하기 전에 기다려야 하는 초 단위 시간입니다. |
| `preimageOracleMinProposalSize` | number | PreimageOracleMinProposalSize는 대용량 preimage oracle 제안의 최소 바이트 수입니다. |
| `preimageOracleChallengePeriod` | number | PreimageOracleChallengePeriod는 challenger가 대용량 preimage 제안에 이의를 제기할 수 있는 초 단위 기간입니다. |
| `proofMaturityDelaySeconds` | number | ProofMaturityDelaySeconds는 증명이 출금 최종 확정에 사용되기 전에 성숙해야 하는 초 단위 시간입니다. |
| `disputeGameFinalityDelaySeconds` | number | DisputeGameFinalityDelaySeconds는 분쟁 게임이 출금 최종 확정에 사용되기 전에 추가로 기다려야 하는 초 단위 시간입니다. |
| `respectedGameType` | number | RespectedGameType은 OptimismPortal 컨트랙트가 출금 최종 확정 시 인정하는 분쟁 게임 유형입니다. |
