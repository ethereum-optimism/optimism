Supersim 포크 모드를 사용하면 컨트랙트를 다시 배포하거나 수정하지 않고도 체인의 상태를 시뮬레이션하고 상호작용할 수 있습니다. 이는 testnet / mainnet 체인에 이미 배포된 컨트랙트를 사용하는 경우에 가능합니다.

```sh
supersim fork
```

## 작동 방식

`supersim` fork 명령은 OP Stack 생태계의 여러 체인을 동시에 포크하는 과정을 단순화합니다. 각 체인에 적합한 블록 높이를 결정하고, 이 값을 기반으로 L1 및 L2 체인을 모두 실행합니다.

이를 통해 [superchain registry](https://github.com/ethereum-optimism/superchain-registry)의 superchain 네트워크에 속한 모든 체인을 로컬에서 포크할 수 있으며, 기본값은 `mainnet` 버전입니다.

## 참고 사항

### 포크 높이

포크 높이는 L1 블록 높이(기본값 `latest`)에 의해 결정됩니다. 이 값은 시작할 해당 L2 블록을 도출하는 데 사용됩니다.

### 상호운용성 컨트랙트

기본적으로 포크된 네트워크에는 상호운용성(interop) 컨트랙트가 배포되지 않습니다. 이를 포함하려면 `--interop.enabled` 플래그와 함께 `supersim`을 실행합니다.

```sh
supersim fork --chains=op,base,zora --interop.enabled
```
