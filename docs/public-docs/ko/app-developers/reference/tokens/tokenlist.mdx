원래 Ethereum에 배포된 다양한 ERC-20 토큰은 OP Mainnet에도 대응하는 "브리지된(bridged)" 버전이 있습니다.
[Superchain Token List](https://github.com/ethereum-optimism/ethereum-optimism.github.io)는 사용자가 각 토큰의 올바른 브리지된 토큰 주소를 찾을 수 있도록 돕기 위해 존재합니다.
이 페이지는 Superchain Token List에서 자동으로 생성됩니다.

<Warning>
**이 페이지에 나열된 토큰은 편의를 위해서만 제공되며** [Superchain Token List](https://github.com/ethereum-optimism/ethereum-optimism.github.io)에서 자동으로 도출됩니다.
**이 페이지에 토큰이 있다고 해서 해당 토큰이나 그 발행자를 보증하는 것은 아닙니다.**
</Warning>

### OP Mainnet의 USDC

<Info>
  주소 `0x7f5c764cbc14f9669b88837ca1490cca17c31607`에 있는 USDC의 레거시 브리지 버전(USDC.e)은 OP Mainnet에서 지원 중단(deprecated)될 예정입니다.
  사용자와 개발자는 [USDC](https://www.circle.com/en/usdc?gad_source=1) 발행사인 [Circle](https://www.circle.com/en/)이 직접 발행하는 네이티브 USDC 토큰으로 마이그레이션해야 합니다.
</Info>

브리지된 `USDC.e` 토큰과 네이티브 USDC 토큰에 대한 정보는 아래에서 확인할 수 있습니다.

| 심볼   | 설명                  | 주소                                                                                                                       |
| -------- | ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `USDC.e` | Ethereum에서 브리지된 USDC   | [`0x7f5c764cbc14f9669b88837ca1490cca17c31607`](https://explorer.optimism.io/token/0x7f5c764cbc14f9669b88837ca1490cca17c31607) |
| `USDC`   | Circle이 발행한 네이티브 USDC | [`0x0b2C639c533813f4Aa9D7837CAf62653d097Ff85`](https://explorer.optimism.io/token/0x0b2c639c533813f4aa9d7837caf62653d097ff85) |
