이 디렉터리는 모든 OP Stack 네트워크의 RPC 엔드포인트를 종합적으로 모아 개발자에게 제공하므로, OP Stack 생태계에서 애플리케이션을 더 쉽게 구축, 배포, 확장할 수 있습니다.

## 공개 RPC 엔드포인트

다음 표에는 모든 OP Stack 네트워크의 공개 RPC 엔드포인트가 나와 있습니다. 이러한 엔드포인트는 **요청 속도 제한(rate limit)이 있으며 프로덕션 용도로 적합하지 않지만**, 개발, 테스트, 개념 증명(PoC) 작업에는 매우 적합합니다.
프로덕션 용도는 아래의 [프로덕션 RPC 제공업체](#production-rpc-providers) 섹션을 참조하세요.

## 프로덕션 RPC 제공업체

다음 제공업체는 OP Stack 네트워크에 대한 프로덕션급 RPC 접근을 제공합니다. 대부분의 제공업체는 공개 RPC보다 높은 요청 속도 한도를 갖춘 무료 등급과 프로덕션 애플리케이션을 위한 유료 플랜을 모두 제공합니다.

**설명**: [1RPC](https://www.1rpc.io/)에서 다음 [네트워크](https://docs.1rpc.io/using-the-web3-api/networks)에 대해 [무료 및 유료 플랜](https://www.1rpc.io/#pricing)을 제공합니다.

**지원되는 Mainnet**: OP Mainnet, Mode, Base

## 디렉터리 거버넌스

OP Stack RPC 디렉터리는 OP Labs가 다음 정책에 따라 관리합니다.

*   제공업체가 추가되려면 [문서](https://github.com/ethereum-optimism/optimism/tree/develop/docs/public-docs/) 저장소에 문서 PR을 제출해야 합니다
*   목록에 등재되려면 제공업체는 [OP Stack 생태계](/ko/op-stack/protocol/superchain-registry)의 네트워크를 하나 이상 지원해야 합니다
*   누구나 등재된 네트워크를 지원하지 않는 제공업체를 제거하기 위한 PR을 제출할 수 있습니다
