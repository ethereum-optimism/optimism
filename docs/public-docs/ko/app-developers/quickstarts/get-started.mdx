OP Stack 체인은 [EVM 동등성(EVM equivalence)](/ko/op-stack/protocol/differences)을 갖추고 있습니다. Ethereum에서 알고 있는 모든 것이 여기에서도 작동하며, 여기에서 구축한 모든 것이 OP Stack 생태계 전반에서 작동합니다.
이 퀵스타트에서는 무료 testnet 자금만 사용하여 OP Sepolia testnet에 컨트랙트를 처음부터 배포하는 과정을 안내합니다.

<Info>
  어느 단계에서도 실제 자금은 필요하지 않습니다. 아래의 모든 내용은 testnet에서 실행됩니다.
</Info>

## 시작하기 전에

다음이 필요합니다.

*   직접 관리하는 지갑(모든 EVM 지갑을 사용할 수 있으며, testnet 전용으로 개인 키를 내보내거나 생성합니다).
*   `curl`을 사용할 수 있는 터미널.

<Warning>
  튜토리얼에는 새로 만든 testnet 전용 개인 키를 사용하세요. 실제 자금이 들어 있는 키를 절대 터미널에 붙여 넣지 마세요.
</Warning>

<Steps>
  <Step title="testnet ETH 받기">

  [Superchain Faucet](https://console.optimism.io/faucet)에서 무료 OP Sepolia ETH를 받으세요.
  다른 옵션은 [testnet faucet 페이지](/ko/app-developers/tools-sdks/faucets)에 나와 있습니다.

  </Step>
  <Step title="OP Sepolia에 연결하기">

  OP Sepolia의 공개 RPC 엔드포인트는 `https://sepolia.optimism.io`이며 chain ID는 `11155420`입니다.
  연결할 수 있는지 확인하세요.

  ```bash
  curl -s -X POST -H "Content-Type: application/json" \
    --data '{"jsonrpc":"2.0","method":"eth_chainId","params":[],"id":1}' \
    https://sepolia.optimism.io
  ```

  예상 결과: `{"jsonrpc":"2.0","id":1,"result":"0xaa37dc"}` (`0xaa37dc` = 11155420).
  다른 네트워크 및 프로덕션급 엔드포인트는 [네트워크 정보](/ko/op-mainnet/network-information/connecting-to-op)와 [RPC 제공업체](/ko/app-developers/reference/rpc-providers)를 참조하세요.

  </Step>
  <Step title="첫 번째 컨트랙트 배포하기">

  [OP Sepolia에 컨트랙트 배포하기](/ko/app-developers/tutorials/deploy-a-contract) 튜토리얼을 따라 하세요.
  이 튜토리얼에서는 Foundry 설치, 작은 `Greeter` 컨트랙트 배포, 그리고 명령줄에서 컨트랙트를 읽고 쓰는 과정을 안내합니다. Ethereum에서 사용하는 것과 동일한 워크플로입니다.

  </Step>
  <Step title="L1과 L2 간 ETH 브리징하기(선택 사항)">

  앱은 종종 Ethereum과 OP Stack 체인 간에 자산을 이동해야 합니다.
  먼저 [브리징 기본 사항](/ko/app-developers/guides/bridging/basics)에서 모델을 이해한 다음, [Viem으로 ETH 브리징하기](/ko/app-developers/tutorials/bridging/cross-dom-bridge-eth) 튜토리얼을 따라 Sepolia → OP Sepolia 입금(디파짓)을 프로그래밍 방식으로 수행해 보세요.

  </Step>
</Steps>
