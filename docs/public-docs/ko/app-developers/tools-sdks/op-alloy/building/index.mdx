이 섹션에서는 다양한 `op-alloy` crate에 대한 심층 문서를 제공합니다.
주요 crate와 해당 타입 중 일부는 다음과 같습니다.

- [`op-alloy-consensus`](https://crates.io/crates/op-alloy-consensus)는 [`OpBlock`](https://docs.rs/op-alloy-consensus/latest/op_alloy_consensus/type.OpBlock.html),
  [`OpTxEnvelope`](https://docs.rs/op-alloy-consensus/latest/op_alloy_consensus/transaction/enum.OpTxEnvelope.html), [`OpReceiptEnvelope`](https://docs.rs/op-alloy-consensus/latest/op_alloy_consensus/enum.OpReceiptEnvelope.html)
  등을 제공합니다.
- [`op-alloy-rpc-types-engine`](https://crates.io/crates/op-alloy-rpc-types-engine)은
  [`OpPayloadAttributes`](https://docs.rs/op-alloy-rpc-types-engine/latest/op_alloy_rpc_types_engine/struct.OpPayloadAttributes.html)를 제공합니다.
