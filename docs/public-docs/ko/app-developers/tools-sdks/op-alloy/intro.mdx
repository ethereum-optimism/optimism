`op-alloy` 시작을 위한 실습 가이드에 오신 것을 환영합니다!

`op-alloy`는 [Alloy](https://github.com/alloy-rs/alloy)의 고성능 타입, 트레이트, 미들웨어를
활용하여 애플리케이션을 OP Stack에 연결합니다.

<Warning>
**개발 상태**

`op-alloy`는 현재 활발하게 개발 중이며, 아직 프로덕션에서 사용할 준비가 되지 않았습니다.
개발 기간 동안 이 문서는 빠르게 변경되며 부정확한 내용이 포함될 수 있습니다.

오류를 발견하거나 개선 제안이 있으면 [이슈를 열어](https://github.com/ethereum-optimism/optimism/issues/new) 주십시오.
또한 프로젝트에 자유롭게 [기여](https://github.com/ethereum-optimism/optimism/blob/develop/CONTRIBUTING.md)해 주십시오!
</Warning>

## 섹션

### [시작하기](/ko/app-developers/tools-sdks/op-alloy/starting)

op-alloy를 시작하려면 해당 crate를 의존성으로 추가하고 첫 단계를 진행합니다.

### [op-alloy로 빌드하기](/ko/app-developers/tools-sdks/op-alloy/building/index)

여러 `op-alloy` crate에서 사용할 수 있는 타입과 기능을 살펴봅니다.

### [기여하기](https://github.com/ethereum-optimism/optimism/blob/develop/CONTRIBUTING.md)

기여자를 환영합니다! 이 프로젝트는 Alloy 기여자, [OP Labs](https://github.com/ethereum-optimism) 구성원,
그리고 더 넓은 오픈소스 커뮤니티가 구축하고 유지 관리합니다.

`op-alloy`는 [사양](https://specs.optimism.io)에 정의된 OP Stack 표준을 따르고 확장합니다.

### 라이선스

`op-alloy`는 Apache 2.0 및 MIT License의 결합 라이선스로 제공되며,
snappy 인코딩 사용에 대해서는 SNAPPY 라이선스가 함께 적용됩니다.
