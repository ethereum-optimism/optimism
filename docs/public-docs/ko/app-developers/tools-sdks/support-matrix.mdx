이 페이지는 OP Stack을 둘러싼 도구와 SDK를 위한 정식(canonical) 허브입니다.
[콘텐츠 가이드](/ko/op-stack/contribute/content-guide)에 따라 각 등재 항목은
정확히 하나의 정식 문서 홈으로 연결됩니다. 이 페이지는 안내만 할 뿐
내용을 다시 서술하지 않습니다. 여기에 무엇이 등재되고 무엇이 삭제되는지는
[등재 기준](/ko/app-developers/tools-sdks/listing-criteria)에 따라 결정됩니다.

## 지원 상태 수준

| 상태 | 의미 |
| --- | --- |
| **Production** | 안정적이며 소유자가 프로덕션 사용을 권장합니다. |
| **Developer preview** | 현재 사용할 수 있지만, 소유자가 아직 프로덕션 준비가 되지 않았다고 선언했습니다. API가 변경될 수 있습니다. |
| **Experimental** | 시험 단계입니다. 기능이 변경되거나 이동하거나 다른 곳으로 업스트림될 수 있습니다. |

## SDK 선택하기

위의 행 중 세 개는 혼동하기 쉬운 TypeScript SDK입니다.
차이점은 다음과 같습니다.

*   **[`viem/op-stack`](https://viem.sh/op-stack)으로 시작하십시오.** viem은
    핵심 라이브러리에서 OP Stack을 정식으로 지원합니다. `viem/op-stack`에서 가져온
    `publicActionsL2()`(및 관련 함수)로 viem 클라이언트를 확장하면
    입금, 출금, L1 gas 추정을 사용할 수 있습니다. 어떤 기능을 여기에서 사용할 수 있다면,
    이곳이 해당 기능의 프로덕션 홈입니다. Super Root 출금 증명에는
    `viem` `2.51.0` 이상이 필요합니다.
*   **viem에 아직 없는 기능이 필요할 때는 [`@eth-optimism/viem`](https://github.com/ethereum-optimism/ecosystem/tree/main/packages/viem)을
    사용하십시오.** 이 패키지의 명시된 목표는 가능한 한 많은 기능을
    viem 자체에 업스트림하는 것입니다. 그때까지는 Superchain 상호운용성 액션 및 기타 프로덕션 이전 기능의
    홈입니다. 이 사이트의
    [상호운용성 튜토리얼](/ko/app-developers/tutorials/interoperability/manual-relay)
    및 [bridge 튜토리얼](/ko/app-developers/tutorials/bridging/cross-dom-bridge-erc20)에서
    이 패키지를 사용합니다.
*   **체인 배관 작업이 아닌 앱 수준의 구성 요소에는 [Actions SDK](/ko/app-developers/quickstarts/actions)를
    사용하십시오.** 두 viem SDK가 프로토콜 작업을 노출하는 반면,
    Actions SDK는 최종 사용자 앱 구축을 위한 wallet, lend, swap
    네임스페이스를 제공합니다. Developer preview 단계이며 아직
    프로덕션에서 사용할 준비가 되지 않았습니다.

TypeScript 대신 Rust로 빌드하십니까? OP Stack 타입과 RPC를 위해서는
[op-alloy](/ko/app-developers/tools-sdks/op-alloy/intro)에서, 실행을 위해서는
[op-revm](/ko/app-developers/tools-sdks/op-revm)에서 시작하십시오. Rust 클라이언트 자체(op-reth, kona-node, kona-client)에
대해서는 [Stack Components 색인](/ko/op-stack/components/index)을 참조하십시오.

## OP Stack에서 wagmi 사용하기

React로 빌드한다면 wagmi로 시작할 가능성이 높으며, wagmi는 OP Stack 체인에서
별도 설정 없이 작동합니다. OP Stack 체인은 표준 EVM 체인이며,
`wagmi/chains`에 해당 정의(`optimism`, `base`, `zora` 및 `viem/chains`의
다른 모든 체인)가 포함되어 있습니다. 읽기, 쓰기, 지갑 연결에는
OP 전용 설정이 필요하지 않습니다.

입금, 출금, 상호운용성과 같은 OP Stack 전용 작업에는
wagmi가 viem의 래퍼라는 점을 활용하십시오.

1.  wagmi 자체의
    [viem 가이드](https://wagmi.sh/react/guides/viem)에 따라
    [`useClient`](https://wagmi.sh/react/api/hooks/useClient) 또는
    [`useConnectorClient`](https://wagmi.sh/react/api/hooks/useConnectorClient)
    hook으로 wagmi에서 viem 클라이언트를 가져옵니다.
2.  해당 클라이언트를 [`viem/op-stack`](https://viem.sh/op-stack)
    액션으로 확장하고 직접 호출합니다.

특히 Superchain 상호운용성의 경우, 실험적인
[`@eth-optimism/wagmi`](https://github.com/ethereum-optimism/ecosystem/tree/main/packages/wagmi)
패키지가 `@eth-optimism/viem` 위에서 React hook(예: `useSendL2ToL2Message`)을
제공합니다. 하위 패키지와 마찬가지로 실험적인 것으로 취급하십시오.
