이 용어집은 지속적으로 갱신되는 문서이며, 새로운 지표가 등장하거나 정의가 바뀌면 업데이트됩니다.

| 지표                    | 측정 대상                                                 | 중요한 이유                                                    |
| ------------------------- | ---------------------------------------------------------------- | ----------------------------------------------------------------- |
| Real Economic Value (REV) | 사용자가 트랜잭션을 위해 지불한 수수료(트랜잭션 수수료 + 프로토콜 외부 팁) | 온체인 활동에 대한 사용자의 지불 의사를 포착합니다           |
| Collective Revenue        | Optimism Collective가 벌어들인 ETH                            | 수익은 거버넌스를 통해 생태계 성장 지원에 사용될 수 있습니다 |
| Total Value Locked (TVL)  | DeFi 프로토콜 및 기타 앱에 예치된 토큰                   | DeFi 생태계의 공급 측면을 나타냅니다                                 |
| Gas Used per Second       | 온체인에서 소비된 평균 연산량                                 | 처리량과 실행 부하를 측정합니다                            |
| Median Transaction Fee    | 사용자가 트랜잭션을 하는 데 드는 일반적인 비용                              | 수수료가 낮을수록 마찰이 줄고 더 폭넓은 사용이 가능해질 수 있습니다           |
| Market Share              | 더 넓은 암호화폐 업계 대비 OP Stack 생태계의 활동 점유율   | L2 또는 더 넓은 시장 대비 상대적 성과를 추적합니다     |

## 수요 측정

### 지불된 트랜잭션 수수료

**지표:** Real Economic Value (REV)

**정의:** 온체인에서 트랜잭션을 실행하기 위해 지불한 총수수료입니다. 여기에는 온체인 포함에 필요한 전통적인 gas 수수료와 트랜잭션 실행 서비스(예: Jito, Flashbots, Timeboost)에 지불한 추가 수수료가 모두 포함됩니다.

**계산:** Gas 수수료 + 프로토콜 외부 팁(예: Jito, Flashbots, Timeboost)

*   프로토콜 외부 팁은 Defillama의 MEV 카테고리에서 가져올 수 있습니다

**중요한 이유:**

*   REV는 "온체인 트랜잭션에 대한 금전적 수요를 측정"하는 최상위 지표입니다(Blockworks).
*   모든 트랜잭션 수수료를 포착하여 실제 수요를 더 잘 반영하므로, 사용자의 지불 의사를 나타내는 대리 지표로 사용됩니다(DEX 스왑 비용과 같은 앱 수준 수수료는 제외).

### 수익

**지표:** 추정 Optimism Collective 수익(Collective Revenue)

**정의:** 수익 공유를 통해 Optimism Collective가 벌어들일 것으로 예상되는 ETH 양입니다.

**계산:** 각 체인에 대해 (a) 체인 수익(Chain Revenue)의 2.5% 또는 (b) 순 온체인 이익(Net Onchain Profit)의 15% 중 큰 값을 취합니다. OP Mainnet은 순 온체인 이익의 100%를 기여합니다.

**주요 구성 요소:**

*   **순 온체인 이익(Net Onchain Profit):** 체인 수익 - L1 Gas 수수료
*   **체인 수익(Chain Revenue):** L1 Data Fee + L2 Base Fee + L2 Priority Fee + L2 Operator Fee의 합계(향후 추가되는 모든 수수료 유형도 포함됩니다.)
*   *L1 Gas 수수료:* 체인이 L1에서 트랜잭션 배치(blob 비용 포함)와 상태 출력 제출 또는 분쟁 게임(dispute game)에 지출한 총 gas 수수료입니다.
*   **트랜잭션 배치:** 트랜잭션의 from 주소가 체인의 `SystemConfigProxy` 컨트랙트에 정의된 `batcherHash` 주소이고, to 주소가 rollup 구성에 정의된 체인의 `batch_inbox_address`인 모든 트랜잭션입니다.
*   **상태 출력 제출 또는 분쟁 게임:** 트랜잭션의 from 주소가 `Proposer`이고, to 주소가 체인의 `SystemConfigProxy` 컨트랙트에 정의된 `outputOracleProxy` 또는 `disputeGameFactoryProxy`인 모든 트랜잭션입니다.
*   각 체인의 `SystemConfigProxy` 컨트랙트는 superchain-registry에서 찾을 수 있습니다.
*   **분쟁 게임 해결:** `disputeGameFactoryProxy`가 생성한 분쟁 게임 컨트랙트로 전송된 트랜잭션 중, 트랜잭션의 method id(함수 호출)가 `Resolve`, `ResolveClaim`, `ClaimCredit` 중 하나인 모든 트랜잭션입니다.

**중요한 이유:**

*   이는 Optimism Collective가 OP Stack 체인을 운영하여 벌어들이는 수익이며, 거버넌스를 통해 생태계 성장 지원에 사용될 수 있습니다.
*   How (and why) the OP Stack drives fees to the Optimism Collective(Optimism 블로그, 2024년 8월)를 참조하십시오.

## 온체인 신호

### 온체인 가치

**지표:** Total Value Locked (TVL)

**정의:** "프로토콜의 스마트 컨트랙트에 보관된 모든 코인의 가치"(Defillama).

**계산:** DefiLlama가 보고하는, 애플리케이션에 예치된 자산의 USD 가치 총합입니다.

*   TVL은 USD 또는 ETH와 같은 암호화폐 자산으로 표시할 수 있지만, 둘 다 가격 변동성의 영향을 받습니다. USD는 해석하기 쉽고 더 넓은 암호화폐 생태계 전반에서 일관되기 때문에 자주 사용됩니다.

**중요한 이유:** TVL은 탈중앙화 거래소(DEX)나 대출 시장과 같은 프로토콜에서 사용되는 온체인 경제 활동의 공급 측면을 나타냅니다. 적절한 곳에 TVL이 충분히 있으면 더 큰 온체인 수요가 가능해질 수 있습니다.

#### 성장 측정 방법: 순 TVL 흐름(Net TVL Flows)

TVL은 시장 변동의 영향을 받기 때문에, 실제 성장이나 사용자 행동을 측정하려 할 때 오해를 불러일으킬 수 있습니다. 순 TVL 흐름은 현재 가격으로 평가한 토큰 잔액의 순변화를 추적하여 이를 보정할 수 있습니다.

**계산:** ( `# of Tokens on Day N` - `# of Tokens on Day 0` ) \* `Price of Tokens on Day N`

**예시:** 어떤 앱에 ETH/USD가 $2,000인 Day 0에 100,000 ETH가 예치되어 있었고, Day N에는 $3,000에서 90,000 ETH가 예치되어 있다면:

*   순 TVL 흐름 = −10,000 ETH × $3,000 = $30 million의 순유출
*   단순 TVL 변화로는 성장한 것처럼 보입니다: $200 million → $270 million

## 네트워크 사용량 및 인프라

**지표:** Gas Used per Second (gas/s)

**정의:** "Gas는 Ethereum에서 특정 작업을 실행하는 데 필요한 연산 노력의 양을 측정하는 단위를 말합니다"(ethereum.org). 단순화를 위해 Gas Used는 초당 평균 비율로 추적합니다.

**중요한 이유:** 블록스페이스라고도 불리는 gas는 블록체인이 제공하는 제한된 자원입니다. Gas 사용량은 그 자원이 실제로 얼마나 소비되고 있는지를 보여줍니다.

**주의:** Gas는 Ethereum과 동등한 gas 단위를 사용하는 체인 간에만 비교할 수 있습니다.

### 사용자 경험(UX)

**지표:** Median Transaction Fee (USD)

**정의:** 트랜잭션을 제출하기 위해 지불한 gas 수수료의 중앙값으로, 단순화와 생태계 간 비교 편의를 위해 USD로 표시합니다.

**계산:** 일정 기간 동안의 모든 트랜잭션 수수료의 중앙값이며, 트랜잭션 시점의 USD 가격으로 환산합니다.

**중요한 이유:** 이 지표는 트랜잭션 비용의 대리 지표 역할을 합니다. 중앙값 수수료가 낮으면 마찰이 줄고 손익분기 비용이 낮아지며, 그렇지 않으면 비용 때문에 불가능했을 사용 사례가 가능해져 더 폭넓은 사용이 이루어질 수 있습니다.

## 시장 점유율

**정의:** 어떤 측정 기준에서든 더 넓은 시장 부문(예: L2, 전체 암호화폐)에서 OP Stack 생태계가 차지하는 점유율입니다.

**계산:** OP Stack 지표 값 / 전체 시장 지표 값

**중요한 이유:** 시장 점유율은 성장이 OP Stack 생태계 자체에 의해 주도되는 것인지, 아니면 단순히 더 넓은 시장 추세의 일부인지를 구분하는 데 도움이 됩니다. 점유율이 상승하면 시장 대비 우수한 성과를 의미하고, 점유율이 하락하면 다른 생태계가 더 빠르게 성장하고 있음을 시사합니다.
