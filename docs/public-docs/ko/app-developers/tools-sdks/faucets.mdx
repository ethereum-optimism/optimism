Faucet은 Sepolia 및 OP Sepolia와 같은 테스트 네트워크에서 무료 ETH(및 기타 토큰)를 받아 트랜잭션을 보내고 스마트 컨트랙트를 생성할 수 있게 해 주는 개발자 도구입니다.
여기에서 사용해 볼 수 있는 활성 faucet 목록을 확인할 수 있습니다.
Faucet마다 사용하는 인증 방식이 다르므로, 사용 가능한 faucet을 찾기까지 몇 가지를 시도해야 할 수도 있습니다.
Faucet의 ETH가 가끔 소진될 수도 있으므로, faucet에서 ETH를 받는 데 문제가 있다면 다른 faucet을 시도해 보십시오.

<Info>
  Sepolia 또는 OP Sepolia와 같은 테스트 네트워크의 토큰은 가치가 없으며 테스트 용도로만 사용됩니다.
  다른 사람들도 faucet을 사용할 수 있도록 Optimist는 필요한 만큼만 가져갑니다!
</Info>

## Optimism faucet

[Optimism faucet](https://console.optimism.io/faucet?utm_source=op-docs&utm_medium=docs)은 Optimism이 호스팅하는 개발자 도구로, 개발자가 무료 testnet ETH를 받아 Base Sepolia, OP Sepolia, PGN Sepolia, Zora Sepolia 및 기타 OP Stack 체인과 같은 testnet OP 체인에서 앱을 테스트할 수 있게 해 줍니다.
testnet ETH를 찾고 있다면 Optimism faucet에서 시작하는 것이 좋습니다.

## Sepolia에서 bridge하기

Sepolia에 testnet ETH가 있다면 [Superchain Bridges UI](https://app.optimism.io/bridge/?utm_source=op-docs&utm_medium=docs) 또는 [Superchain Testnet Tools](https://www.superchain.tools/) 모음을 사용하여 OP Sepolia로(또는 그 반대로) bridge할 수 있습니다.
