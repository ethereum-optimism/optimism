이 페이지에서는 `supersim`의 설치 방법을 안내합니다.

<Steps>
  <Step title="사전 요구 사항: foundry">
  `supersim`에는 Foundry 툴체인과 함께 설치되는 `anvil`이 필요합니다.
  
    자세한 안내는 [Foundry 툴체인](https://book.getfoundry.sh/getting-started/installation) 가이드를 따르십시오.
  </Step>

  <Step title="supersim 설치하기">
  미리 컴파일된 바이너리를 다운로드하거나 Homebrew를 사용하여 설치합니다.
  
    *   미리 컴파일된 바이너리: [GitHub 릴리스 페이지](https://github.com/ethereum-optimism/supersim/releases)에서 사용 중인 플랫폼에 맞는 실행 파일을 다운로드합니다.
  
    *   Homebrew: [Homebrew](https://brew.sh/)(OS X, Linux)를 설치한 다음 다음 명령을 실행합니다.
  
    ```sh
    brew tap ethereum-optimism/tap
    brew install supersim
    ```
  </Step>

  <Step title="vanilla 모드로 supersim 시작하기">
  다음 명령을 실행하여 `supersim`을 vanilla 모드로 시작합니다.
  
      ```sh
    supersim
    ```
    vanilla 모드는 OP Stack 컨트랙트가 이미 배포된 3개의 체인을 시작합니다.
    
      *   (1) L1 체인
          *   Chain 900
      *   (2) L2 체인
          *   Chain 901
          *   Chain 902
  </Step>
</Steps>
