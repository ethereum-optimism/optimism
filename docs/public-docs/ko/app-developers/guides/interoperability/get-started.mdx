OP Stack interop으로 앱을 새롭게 구상하여 사용자가 기대하는 통합된 UX를 제공하십시오. Interop devnet에서 완전히 새롭고 과감한 사용 사례를 개발해 보십시오.

<Info>
  [Superchain Dev Console](https://console.optimism.io/?utm_source=op-docs&utm_medium=docs)을 살펴보고 OP Stack 체인에서 앱을 구축, 출시, 성장시키십시오.
</Info>

## OP Stack Interop에 연결하기

앱을 구축하고 테스트하며 빠르게 반복 개발할 수 있는 개발 환경을 선택하십시오.

| 환경           | 목적                                   | 시작하기                                            |
| --------------------- | ----------------------------------------- | ---------------------------------------------------------- |
| **로컬 개발** | Supersim을 사용한 빠른 반복 개발 및 테스트 | [Supersim 설정 가이드](/ko/app-developers/tutorials/development/supersim/installation) |
| **Interop devnet**    | testnet에서의 대규모 테스트           | [네트워크 사양](/ko/app-developers/guides/building-apps)                     |

| 도구                                                                                       | 설명                                                             |

| [Developer Support GitHub](https://github.com/ethereum-optimism/developers/discussions)    | 빠르고 간편한 개발자 지원을 제공합니다.                                       |

## OP Stack Interop으로 완전히 새로운 사용 사례 발견 및 구축하기

브리지 추상화 외에도 할 수 있는 일이 훨씬 많습니다. OP Stack Interop으로만 가능한 다양한 최첨단 애플리케이션을 개발해 보십시오. 시작하는 데 도움이 될 몇 가지 아이디어는 다음과 같습니다.

| Superloans                                                                         | Superlend                                                                                                           | SuperCDP                                                                                                         |
| :--------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------ | :--------------------------------------------------------------------------------------------------------------- |
| ChainA와 ChainB의 담보를 사용하여 ChainA에서 차익 거래 기회를 실행합니다. | 최적의 수익을 위해 여러 체인의 대출 프로토콜에 ETH를 입금하고, 최적 금리에 따라 자동으로 리밸런싱합니다. | 자산을 보유하고 사용자가 선호하는 체인에서 크로스체인 토큰을 발행하는 담보 기반 크로스체인 부채 프로토콜입니다. |
