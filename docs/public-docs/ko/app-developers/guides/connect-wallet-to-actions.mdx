Actions SDK는 트랜잭션이 어디서 어떻게 서명되는지와 관계없이 널리 사용되는 임베디드 지갑 제공업체의 지갑과 함께 작동합니다.
이 가이드에서는 제공업체 지갑을 Actions에 연결하여 Actions 함수를 호출할 수 있도록 하는 방법을 보여 줍니다.

사용 사례에 맞는 지갑 스키마를 결정하는 데 도움이 필요하면 [지갑 통합하기](/ko/app-developers/reference/actions/integrating-wallets)를 참고하십시오.

## 지갑 연결하기

<Steps>
  <Step title="지갑 제공업체 선택">
    임베디드 지갑 제공업체의 문서와 설치 단계를 따르십시오.
    Actions는 프런트엔드 React와 백엔드 Node 모두의 Typescript 클라이언트에서 작동합니다.
  </Step>
  <Step title="Actions SDK 가져오기">
    선택한 지갑 제공업체 SDK와 함께 [Actions SDK](https://actions.money/)를
    import합니다.
    [빠른 시작](/ko/app-developers/quickstarts/actions#installation)에서
    프로젝트에 Actions SDK를 설치하는 방법을 다룹니다.
  </Step>
  <Step title="임베디드 사용자 지갑 생성 및 조회">
    지갑 생성 및 접근에 대해서는 임베디드 지갑 제공업체의 문서를
    따르십시오.
  </Step>
  <Step title="Actions에 지갑 전달">
    `actions.wallet.toActionsWallet(...)`을 호출하고 제공업체 지갑을
    [전달](/ko/app-developers/quickstarts/actions#choose-a-wallet-provider)합니다.
    빠른 시작에는 프런트엔드와 백엔드 클라이언트 모두에 대한 제공업체별 코드
    예시가 포함되어 있습니다.
  </Step>
  <Step title="작업 실행">
    반환된
    [Wallet](/ko/app-developers/reference/actions/wallet-definitions)은 이제
    Lend, Borrow, Swap, Pay와 같은 Actions
    [함수](/ko/app-developers/quickstarts/actions#take-action)를
    호출할 수 있습니다!
  </Step>
</Steps>

## 다음 단계

*   [Actions 설정하기](/ko/app-developers/guides/configuring-actions) 가이드를 따라 지원할 프로토콜, 체인, 자산을 정의하십시오.
*   사용자의 임베디드 지갑이 제어하는 스마트 컨트랙트 지갑을 Actions가 배포하도록 하려면 [스마트 지갑 및 서명자](/ko/app-developers/reference/actions/integrating-wallets#smart-wallets--signers)에 대해 알아보십시오.
*   지갑 클래스, 함수, 매개변수에 대한 API 세부 정보는 [Wallet 문서](/ko/app-developers/reference/actions/wallet-definitions)를 참고하십시오.
