하나의 네이티브 토큰은 다른 체인에서 둘 이상의 브리지 표현을 가질 수 있으며, 같은 네이티브 토큰의 서로 다른 브리지 표현은 완전히 독립적인 토큰입니다.
잘못된 표현으로 브리지하면 네이티브 토큰이 영구적으로 잠길 수 있습니다.
이 가이드에서는 [Standard Bridge](/ko/app-developers/guides/bridging/standard-bridge)로 토큰을 브리지하기 전에 [Superchain Token List](https://github.com/ethereum-optimism/ethereum-optimism.github.io)를 사용하여 올바른 브리지 토큰 주소를 찾고 검증하는 방법을 보여 줍니다.

## OP Mainnet용 토큰의 브리지 표현 찾기

OP Mainnet용 토큰의 브리지 표현은 [브리지 토큰 주소](/ko/app-developers/reference/tokens/tokenlist) 페이지에서 쉽게 찾을 수 있습니다.
이 페이지는 Superchain Token List로부터 자동으로 생성됩니다.

## 다른 체인용 토큰의 브리지 표현 찾기

다른 체인용 토큰의 브리지 표현을 찾으려면 다음 단계를 따르십시오.

<Steps>
  <Step title="브리지할 토큰 찾기">
    Superchain Token List는 토큰의 주소와 네이티브 블록체인을 기준으로 구성되어 있습니다.
    브리지하려는 토큰을 [토큰 목록에서 검색](https://github.com/ethereum-optimism/ethereum-optimism.github.io/blob/master/optimism.tokenlist.json)하여 목록에 포함되어 있는지 확인하십시오.
    항목의 chain ID가 브리지를 시작하는 블록체인의 chain ID와 일치하는지 확인하십시오.
    목록에서 토큰의 이름과 심볼을 확인합니다.
  </Step>

  <Step title="토큰의 브리지 표현 찾기">
    브리지할 토큰을 찾았다면, 목록에서 해당 토큰의 이름과 심볼을 찾으십시오.
    브리지하려는 토큰의 이름 및 심볼과 일치하고, chain ID가 브리지 대상 블록체인의 chain ID와 일치하는 항목을 찾습니다.
    이 항목의 주소가 브리지하려는 토큰의 브리지 표현 주소입니다.
  </Step>

  <Step title="토큰 쌍이 사용하는 브리지 컨트랙트 주소 찾기">
    토큰 쌍이 사용하는 크로스체인 브리지 컨트랙트 주소를 확인합니다.
    목록의 일부 토큰 쌍은 기본 Standard Bridge 대신 **커스텀 브리지 컨트랙트**를 사용한다는 것을 확인할 수 있습니다.
    토큰 목록 항목에 지정된 브리지 컨트랙트를 검증하여 해당 토큰에 맞는 올바른 브리지 구현과 상호작용하고 있는지 확인하십시오.
  </Step>
</Steps>

## Superchain Token List에 토큰 추가하기

자체 브리지 토큰을 만드는 개발자는 Superchain Token List에 [토큰을 추가](https://github.com/ethereum-optimism/ethereum-optimism.github.io#adding-a-token-to-the-list)하는 것을 고려하십시오.
Superchain Token List에 등록된 토큰은 [Superchain Bridges UI](https://app.optimism.io/bridge?utm_source=op-docs&utm_medium=docs)와 같은 특정 도구에 자동으로 표시됩니다.
