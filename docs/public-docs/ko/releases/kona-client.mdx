**kona-client**는 MIPS prover에서 OP Stack 상태 전이를 실행하는 베어메탈 결함 증명(fault proof) 프로그램입니다. OP Stack 체인의 기본 결함 증명 프로그램입니다. [결함 증명 사양](https://specs.optimism.io/fault-proof/index.html)을 참조하십시오.

## 개요

> [!IMPORTANT]
> 이번 릴리스는 결함 증명 건전성(soundness) 수정, op-node와의 derivation 정렬, 상호운용성(interop) 기반 작업을 포함한 kona-client의 주요 릴리스입니다. kona-client 결함 증명을 실행하는 모든 체인에서 필수 업그레이드입니다.

## 개요

이번 릴리스는 kona-client의 패치 릴리스입니다. Glamsterdam(EIP-7904)에 맞추어 FPVM precompile oracle gas를 상향하고, op-program과 일치하도록 interop trace-extension 경계를 강화하며, 잘못된 형식의 output-root preimage를 명시적으로 드러냅니다. L1에서 Glamsterdam이 활성화되기 전에는 필수이며, 그 외의 경우에는 선택 사항입니다.
