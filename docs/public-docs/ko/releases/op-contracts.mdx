- Custom Gas Token v2: SystemConfig의 CUSTOM_GAS_TOKEN 기능 플래그로 제어되며, 배포 시 이 기능을 활성화하는 신규 체인을 대상으로 합니다.
- Creator Pattern 분쟁 게임 리팩터링: 분쟁 게임(dispute game) 컨트랙트를 효율적으로 배포하여 단일 구현을 모든 체인에서 사용할 수 있도록 합니다(이후 각 체인별로 복제되어 개별적으로 구성됨).
- Cannon + Kona: 이 업그레이드는 Cannon [Fault Proof VM](https://specs.optimism.io/fault-proof/index.html#fault-proof-vm)과 함께 [Kona Proof](https://github.com/ethereum-optimism/optimism/tree/develop/kona/crates/proof/proof)를 사용하는 [새로운 게임 유형](https://github.com/ethereum-optimism/optimism/blob/b9dc5808f61c160de048fb7db39a04fe4fba4574/packages/contracts-bedrock/src/dispute/lib/Types.sol#L76-L77)을 추가합니다. respected game type은 변경하지 않습니다. (`b9dc580` 기준)

감사 결과는 [여기에 게시되어 있습니다](https://github.com/ethereum-optimism/optimism/blob/develop/docs/security-reviews/2026_01-U18-Cantina.pdf).

> [!WARNING]
> 이 릴리스의 `op-deployer/justfile` 파일은 배포에 절대 사용해서는 안 됩니다(MUST NOT). 사용할 경우 이전 MIPS 버전으로 배포하게 됩니다. 이 커밋에 포함된 컨트랙트를 배포하려면 대신 최신 `op-deployer/v*` 릴리스를 사용하십시오.
