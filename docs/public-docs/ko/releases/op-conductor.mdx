**op-conductor**는 Raft 합의를 사용하여 sequencer의 고가용성을 관리합니다. 다중 node sequencer 클러스터를 조정하여 unsafe reorg가 발생하지 않도록 보장하고, 최대 1개 node 장애 시에도 지속적인 가동 시간을 유지합니다.

## throttling 메시지를 위한 투명하고 무조건적인 프록시
이 릴리스에서 conductor는 `miner_setMaxDASize` API 호출을 다음과 같이 전달하도록 업데이트되었습니다.
* 투명하게 — 즉, 원본 sequencer가 오류를 반환하면 오류를 반환합니다.
* 무조건적으로 — 즉, 원본 sequencer가 현재 리더가 아니더라도 호출을 프록시합니다.

> [!IMPORTANT]
> 업그레이드를 강력히 권장합니다. 최신 op-batcher 릴리스로 업데이트하는 경우 이 버전의 op-conductor로도 반드시 업그레이드해야 합니다. 해당 batcher 릴리스부터는 활성 sequencer뿐만 아니라 모든 엔드포인트가 항상 throttling되기 때문입니다.
