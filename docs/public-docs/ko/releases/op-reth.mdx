> 이제 보안(`wss://`) flashblocks 엔드포인트가 정상적으로 동작합니다. 이전에는 모든 `wss://` flashblocks URL이 첫 번째 TLS 핸드셰이크에서 panic이 발생했습니다([#21898](https://github.com/ethereum-optimism/optimism/pull/21898)).
