**kona-host**는 prover와 함께 네이티브로 실행되며, 증명 실행 중 kona-client에 체인 데이터를 제공하는 [Preimage Oracle](https://specs.optimism.io/fault-proof/index.html) 서버 역할을 합니다.

<Update label="September 8, 2026" description="v1.7.0" tags={["Latest", "Stable"]}>

## 개요

> [!IMPORTANT]
> 이번 릴리스는 크래시 수정, 결함 증명 건전성(soundness) 수정, op-node와의 derivation 정렬, 상호운용성(interop) 기반 작업을 포함한 kona-host의 주요 릴리스입니다. kona-client 결함 증명을 실행하는 모든 체인에서 필수 업그레이드입니다.

참고: Lagoon(interop)은 아직 프로덕션에서 활성화되지 않았습니다. 이번 릴리스에서 해당 코드 경로에 대한 변경 사항은 향후 기능을 위한 준비 작업이며, 현재 운영자에게는 영향을 주지 않습니다.
