# Docs 스타일 가이드

이 가이드는 렌더링된 문서 사이트로 이동했습니다. 현재
[docs.optimism.io/op-stack/contribute/style-guide](https://docs.optimism.io/op-stack/contribute/style-guide)에 게시되어 있습니다.

정식 소스는 이 디렉터리의 [`op-stack/contribute/style-guide.mdx`](op-stack/contribute/style-guide.mdx)입니다.
스타일 가이드를 변경하려면 이 파일이 아니라 해당 페이지를 수정하십시오.

docs.optimism.io에 포함될 콘텐츠에 대해서는
[콘텐츠 가이드](https://docs.optimism.io/op-stack/contribute/content-guide)
([소스](op-stack/contribute/content-guide.mdx))를 참고하십시오. 개발 환경 설정 및
pull request 절차는 [DOCS_CONTRIBUTING.md](DOCS_CONTRIBUTING.md)를 참고하십시오.
