이 섹션의 각 페이지는 **솔루션 가이드**입니다. 실무에서 여러 구성 요소에 걸쳐 있는
하나의 목표를 사이트 내의 단일 경로로 순서대로 정리한 것입니다. 솔루션 가이드는
각 단계를 해당 정식 페이지에 연결하고 그 페이지에서 무엇을 얻어야 하는지 설명하며,
어떤 단일 구성 요소 페이지도 담을 수 없는 의사 결정 로직을 추가합니다. 또한
엄선되고 실제로 작동하는 외부 링크를 통해서만 사이트를 벗어납니다. 여러분의 목표가
여기에 나열되어 있다면, 경로를 직접 구성하는 대신 여기서 시작하십시오.
