공지는 애플리케이션 개발자, 노드 운영자, 체인 운영자를 위한 기한이 정해진 조치 항목으로, 예정된
네트워크 업그레이드, 지원 중단, 운영 변경 사항을 다룹니다. 각 하드포크는
[하드포크 레지스트리](/ko/op-stack/protocol/network-upgrades)에도 영구 항목이 있으며,
여기에는 활성화 시점, 기준 사양, 최소 구성 요소 버전이 기록됩니다.
컨트랙트 전용 업그레이드는 레지스트리의
[컨트랙트 업그레이드 표](/ko/op-stack/protocol/network-upgrades#contract-upgrades)에 나열됩니다.
공지는 활성화 이후 보관 처리되지만, 레지스트리 페이지는 영구적으로 유지됩니다.
