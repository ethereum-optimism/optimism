<Warning>
  Subblocks는 Flashblocks를 대체합니다. Flashblocks는 더 이상 OP Stack 체인에서 공식적으로 지원되지 않습니다.
  단계적 종료 일정은 [사전 확인(preconfirmation) 아키텍처 전환 공지](/ko/notices/preconfirmation-architecture-transition)를 참조하세요.
</Warning>

Subblocks는 OP Enterprise 고객만 사용할 수 있는 비공개 기능입니다. OP Enterprise 고객이 되는 데 관심이 있다면 [OP Enterprise 팀에 문의하세요](https://optimism.io/learn-more). 자세한 내용은 [Subblocks 설명](/ko/op-stack/features/subblocks)을 참조하세요.
