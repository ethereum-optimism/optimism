## 주요 플래그 참고 사항

### raft.bootstrap

<Info>
  새 클러스터를 부트스트랩하기 위한 플래그입니다. 현재 활성 상태인 sequencer에서만
  사용해야 하며, 이 플래그로는 한 번만 시작할 수 있습니다. 그렇지 않으면 클러스터를
  다시 부트스트랩하기 전에 플래그를 제거하거나 raft 로그를 삭제해야 합니다.
</Info>

### paused

<Info>
  구성 상태가 저장되지 않으므로, RPC로 일시 정지를 해제한 후 재시작하면
  다시 일시 정지된 상태로 시작됩니다.
</Info>

## RPCs

Conductor는 `conductor` 네임스페이스에서
[admin RPC](https://github.com/ethereum-optimism/optimism/blob/develop/op-conductor/rpc/api.go#L17)를 제공합니다.

### conductor_overrideLeader

`OverrideLeader`는 리더 상태를 재정의하는 데 사용되며, `Leader()` 및 `LeaderWithID()`
호출이 true를 반환하도록 하는 용도로만 사용됩니다. 실제 raft 합의 리더십 상태에는
영향을 주지 않습니다. 클러스터가 비정상 상태이고 해당 node만 동작 중일 때 사용하도록
의도되었으며, batcher가 해당 node에 연결하여 수동으로 시작한 sequencer로부터 블록을
다운로드할 수 있도록 합니다.

<Tabs>
  <Tab title="curl">
    ```sh
    curl -X POST -H "Content-Type: application/json" --data \
        '{"jsonrpc":"2.0","method":"conductor_overrideLeader","params":[],"id":1}'  \
        http://127.0.0.1:8547
    ```
  </Tab>

  <Tab title="cast">
    ```sh
    cast rpc conductor_overrideLeader --rpc-url http://127.0.0.1:8547
    ```
  </Tab>
</Tabs>
