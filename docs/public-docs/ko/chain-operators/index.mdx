자체 OP Stack 체인을 출시하거나 운영하고 있다면, 먼저 배포한 다음
가이드, 도구, 레퍼런스 자료를 활용하여 프로덕션에서 운영하세요.

<CardGroup cols={2}>
  <Card title="체인 배포" href="/ko/chain-operators/quickstart">
    op-deployer로 첫 번째 OP Stack 체인을 출시합니다.
  </Card>
  <Card title="체인 구성 및 관리" href="/ko/chain-operators/guides/configuration/getting-started">
    batcher, proposer, challenger를 설정하고, 기능을 활성화하며,
    프로덕션 모범 사례를 따릅니다.
  </Card>
  <Card title="튜토리얼 따라 하기" href="/ko/chain-operators/tutorials/create-l2-rollup">
    구성 요소별로 rollup을 구축하고, L1 컨트랙트를 업그레이드하며,
    단계별로 체인을 사용자 정의합니다.
  </Card>
  <Card title="지원 도구 실행" href="/ko/chain-operators/tools/op-deployer/overview">
    체인을 건강하게 유지하는 op-deployer, op-conductor, 체인 모니터링,
    RPC 프런트엔드를 운영합니다.
  </Card>
  <Card title="구성 레퍼런스 찾아보기" href="/ko/chain-operators/reference/batcher-configuration">
    batcher, challenger, 배포 구성, 수수료 파라미터에 대한 플래그 수준
    레퍼런스를 확인합니다.
  </Card>
  <Card title="자체 체인을 운영하지 않으시나요?" href="/ko">

    학습자를 위한 섹션이 각각 마련되어 있습니다.
  </Card>
