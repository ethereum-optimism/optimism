kona-node는 [Kona](https://github.com/ethereum-optimism/optimism/tree/develop/rust/kona) 프로젝트의
일부로 빌드되는 OP Stack 합의 계층(rollup node) 클라이언트의 Rust 구현입니다.

## 개요

kona-node는 [op-node](/ko/op-stack/protocol/components)와 동일한 프로토콜 역할을 수행합니다.
데이터 가용성 계층에서 배치 데이터와 입금(디파짓)을 읽고, 정식 L2 체인을 파생하며, Engine API를
통해 실행 계층 클라이언트(예: [op-reth](/ko/node-operators/guides/configuration/execution-clients))를
구동합니다. 또한 unsafe 블록 gossip 네트워크에 참여하며 sequencer 모드로 실행할 수도 있습니다.

kona-node는 OP Stack에 클라이언트 다양성을 제공하기 위해 존재합니다. 독립적인 rollup node 구현이
있으면 한 클라이언트의 버그가 체인의 모든 node를 중단시킬 수 없습니다. Kona는 활발히 개발 중이며
kona-node는 실험적인 것으로 간주해야 합니다.

**운영 주체:** 노드 운영자가 실행 클라이언트와 짝을 이루는 node 스택의 합의 계층 절반으로
운영합니다. 체인 운영자도 sequencer 모드로 실행할 수 있습니다.
