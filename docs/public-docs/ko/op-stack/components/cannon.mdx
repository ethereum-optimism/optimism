cannon은 OP Stack의 결함 증명(fault proof) 가상 머신(FPVM)입니다. 분쟁 대상이 된 L2
상태 전이를 L1에서 명령어 단위로 재실행할 수 있게 해 주는 온체인 MIPS 명령어
에뮬레이터입니다.

## 개요

cannon은 동일하게 동작해야 하는 두 부분으로 구성됩니다.

*   **온체인 `MIPS64.sol`** — 빅엔디언 64비트 MIPS(MIPS64r1) 명령어 실행을 Solidity로
    구현한 것으로, L1에서 분쟁 대상인 단일 명령어를 검증하는 데 사용됩니다.
*   **오프체인 `mipsevm`** — 동일한 명령어 집합에 대한 계측(instrumented) 에뮬레이터로,
    전체 프로그램을 실행하고 임의의 한 단계를 온체인에서 반복하는 데 필요한 witness
    데이터를 생성합니다.

cannon이 실행하는 프로그램은 MIPS ELF 바이너리로 컴파일된 결함 증명 프로그램
[kona-client](/ko/releases/kona-client)이며, [kona-host](/ko/releases/kona-host) 바이너리는
실행 중 체인 데이터를 제공하는 preimage 서버로 함께 실행됩니다. 이 둘이 함께 결함 분쟁을
해결 가능하게 만듭니다. 참여자들은 실행 트레이스를 이분 탐색하여 단일 MIPS 명령어까지
좁히고, 그 하나의 명령어를 온체인에서 증명합니다.

**운영 주체:** 일반 노드 운영자가 아니라 분쟁 게임(dispute game) 참여자입니다.
[op-challenger](/ko/op-stack/fault-proofs/challenger)는 결함 분쟁이 실행 트레이스 단계에
도달하면 cannon 바이너리를 자동으로 호출하며, 체인 운영자는 무허가 결함 증명을 구성할 때
cannon prestate를 빌드합니다. cannon이 분쟁 게임에서 어떤 역할을 하는지는
[결함 증명 설명](/ko/op-stack/fault-proofs/explainer)과
[Cannon](/ko/op-stack/fault-proofs/cannon), [MIPS](/ko/op-stack/fault-proofs/mips) 심층 설명
페이지를 참조하십시오.
