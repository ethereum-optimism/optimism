도입했습니다.

## 변경 사항

[명세 개요](https://specs.optimism.io/protocol/isthmus/overview.html)에 따른 변경 사항은 다음과 같습니다.

*   L2에 Pectra EIP 적용. 여기에는
    [EIP-7702](https://eips.ethereum.org/EIPS/eip-7702)(EOA 계정 코드 설정),
    [EIP-2537](https://eips.ethereum.org/EIPS/eip-2537)(BLS12-381
    precompile), [EIP-2935](https://eips.ethereum.org/EIPS/eip-2935)
    (상태에 과거 블록 해시 저장),
    [EIP-7623](https://eips.ethereum.org/EIPS/eip-7623)(calldata 비용
    인상)이 포함됩니다. [EIP-7002](https://eips.ethereum.org/EIPS/eip-7002) 및
    [EIP-7251](https://eips.ethereum.org/EIPS/eip-7251)의 predeploy 컨트랙트와
    syscall은 OP Stack에서 채택하지 않습니다.
*   블록 헤더에 `L2ToL1MessagePasser` 스토리지 루트 포함.
*   [Operator fee](https://specs.optimism.io/protocol/isthmus/exec-engine.html#operator-fee).
*   스마트 컨트랙트: predeploy, L1 블록 attributes, `SystemConfig` 업데이트.

[Upgrade 15 공지](/ko/notices/archive/upgrade-15)에서 활성화에 수반된 운영자 작업
단계를 다룹니다.
