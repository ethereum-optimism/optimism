## 변경 사항

[명세 개요](https://specs.optimism.io/protocol/jovian/overview.html)에 따른 변경 사항은 다음과 같습니다.

*   실행 계층:
    [최소 base fee](https://specs.optimism.io/protocol/jovian/exec-engine.html#minimum-base-fee),
    [DA footprint 한도](https://specs.optimism.io/protocol/jovian/exec-engine.html#da-footprint-block-limit),
    [operator fee](https://specs.optimism.io/protocol/jovian/exec-engine.html#operator-fee)
    변경.
*   합의 계층: derivation 중에 적용되는 네트워크 업그레이드 트랜잭션,
    `L1Block`(L1 attributes) predeploy의 자동 업그레이드 및 확장.
*   스마트 컨트랙트: `SystemConfig` 업데이트.

[Upgrade 17 공지](/ko/notices/archive/upgrade-17)에서 활성화에 수반된 운영자 작업
단계를 다룹니다.
