이 섹션은 docs.optimism.io에서 프로토콜 계층의 홈입니다. 프로토콜 동작은
[OP Stack 명세](https://specs.optimism.io/)에 규범적으로 정의되어 있습니다.
[콘텐츠 가이드](/ko/op-stack/contribute/content-guide)에 따라, 이곳의 페이지들은
개념을 설명하고 정확한 명세 섹션으로 안내할 뿐, 규범적 내용을 다시 서술하지
않습니다.
