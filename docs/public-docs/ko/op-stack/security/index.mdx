OP Stack 체인을 보호하는 안전장치, 권한 역할의 책임, 보안 위협에 대응하는
절차를 이해하십시오. 보안 감사를 검토하고, 취약점을 보고하며, 안전한 통합과
출금 일시 중지에 관한 안내를 따르십시오.
