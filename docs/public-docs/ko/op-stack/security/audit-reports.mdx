보안은 OP Stack의 최우선 과제입니다.
아래에서 OP Stack 생태계의 다양한 구성 요소에 대해 수행된 과거 감사의 전체 목록을 확인할 수 있습니다.
각 보고서에는 범위, 중점 사항, 전체 감사 문서 링크가 포함되어 있습니다.
이러한 검토는 모든 사용자에게 시스템이 안전하고 신뢰할 수 있도록 보장합니다.

지금까지 수행된 모든 보안 감사는 [모노레포](https://github.com/ethereum-optimism/optimism/tree/develop/docs/security-reviews#security-reviews)에서 확인할 수 있습니다.
