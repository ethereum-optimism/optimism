이 가이드에서는 OP Stack preinstall과 이것이 개발자에게 제공하는 이점을 설명합니다.
새 체인에서 프로덕션을 시작하려면 개발자에게 핵심 컨트랙트가 필요합니다. Gnosis Safe, 4337 entrypoint, create2deployer 등이 그 예입니다. 빈 EVM에서는 이러한 컨트랙트를 배포하는 데 몇 주가 걸릴 수 있습니다. 이제 핵심 컨트랙트가 OP Stack에 *사전 설치(preinstalled)*되어 제공되므로 서드파티 배포가 필요하지 않습니다.
혼자 개발하든 차세대 대형 rollup을 시작하든, 개발자는 체인을 구동하는 즉시 선호하는 컨트랙트를 사용할 수 있습니다.

Preinstall은 이러한 핵심 스마트 컨트랙트를 L2 제네시스 상태의 일반적인 주소에 배치하여, 체인이 초기화되는 즉시 사용할 수 있도록 보장합니다.
이러한 컨트랙트가 정해진 주소에 사전 설치되므로, 개발자는 OP Stack 체인의 정해진 주소에 이 모든 컨트랙트가 존재할 것이라고 기대할 수 있습니다.

<Info>
  Preinstall은 Ecotone 이후의 모든 새 OP 체인에서 자동으로 활성화됩니다.
</Info>
