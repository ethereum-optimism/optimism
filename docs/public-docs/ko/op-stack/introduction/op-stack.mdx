OP Stack은 Optimism을 구동하고 프로덕션 Layer 2 블록체인 운영을
가능하게 하는 표준화된 공유 오픈 소스 개발 스택입니다. OP Stack은
단일 프로그램이 아닙니다. 여러 구성 요소가 함께 동작하여 전체 이력이
Ethereum에 게시되는 체인을 만들어 내며, 따라서 누구나 체인을 재구성하고
검증할 수 있습니다.

## OP Stack이 제공하는 것

OP Stack 체인은 *rollup*입니다. 즉, 자체 네트워크에서 트랜잭션을 실행하고
해당 트랜잭션의 데이터를 상위 체인(보통 Ethereum)에 게시합니다. 데이터가
게시되므로 누구나 상위 체인만으로 체인을 재구축할 수 있으며, Ethereum은
체인의 상태를 충분히 신뢰하여 체인 밖으로 자금을 다시 내보낼 수 있습니다.

이러한 구조 덕분에 체인들이 OP Stack 위에 구축되는 이유가 되는 다음과 같은 특성이 생겨납니다.

*   **EVM 동등성.** 기존 Ethereum 컨트랙트와 도구를 수정 없이 그대로
    사용할 수 있습니다. 의도적으로 다르게 설계된 소수의 차이점은
    [Ethereum과의 차이점](/ko/op-stack/protocol/differences)에 문서화되어 있습니다.
*   **Ethereum보다 훨씬 낮은 비용.** 트랜잭션은 L2에서 실행되며, 압축된
    데이터만 L1에 도달합니다.
    [트랜잭션 수수료](/ko/op-stack/transactions/fees)를 참조하십시오.
*   **Ethereum 최종성에 기반한 빠른 확인.** 블록은 몇 초 만에 생성되며,
    데이터가 Ethereum에서 최종 확정되면 되돌릴 수 없게 됩니다.
    [트랜잭션 최종성](/ko/op-stack/transactions/transaction-finality)을 참조하십시오.
*   **모듈성.** 데이터 가용성, 시퀀싱, 정산이 별도의 계층으로 분리되어
    있어, 체인은 나머지를 재구축하지 않고도 하나의 계층을 변경할 수 있습니다.

## OP Stack이 구동하는 것

OP Stack은 OP Mainnet을 비롯한 수많은 프로덕션 체인을 구동하며, 이 중 다수는
표준 구성, 컨트랙트, 업그레이드 프로세스를 따릅니다. 이러한 공유 표준 덕분에
공통 도구 체인과 네이티브 OP Stack 크로스체인 상호운용성(interoperability)이
가능해집니다.
