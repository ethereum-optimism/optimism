            [default: 25]

            Use the trie-state snapshot to accelerate per-block reads during backfill. If no snapshot exists, one is bootstrapped at the current `earliest` before the backfill loop begins. Requires v2 storage.

            Defaults to `true`. Pass `--proofs-history.use-snapshot false` to force the non-snapshot path (per-block reads via the reth DB).
