---
title: "Admin RPC Methods"
diataxis: reference
---

Enable `--rpc.enable-admin` to expose these methods. Payload submission and engine reset work in both validator and sequencer modes. Sequencer controls are registered only on sequencer nodes; unavailable methods return Method not found.

## `admin_postUnsafePayload`

Validates the payload block hash and waits for bounded engine admission. Success precedes execution, and the node does not gossip this submission.

| Client | Method invocation                                           |
| ------ | ----------------------------------------------------------- |
| RPC    | `{"method": "admin_postUnsafePayload", "params": [payload]}` |

### Parameters

- `payload` (`OpExecutionPayloadEnvelope`): The execution payload envelope to post

### Example

```js
// > {"jsonrpc":"2.0","id":1,"method":"admin_postUnsafePayload","params":[{...payload...}]}
{"jsonrpc":"2.0","id":1,"result":null}
```

## `admin_resetDerivationPipeline`

Resets the engine forkchoice and invalidates earlier derivation work. Success acknowledges
completed recovery after the engine publishes its new epoch and accepted heads. Derivation
consumes that publication independently; a full sequencer mailbox cannot delay the reset.

```js
// > {"jsonrpc":"2.0","id":1,"method":"admin_resetDerivationPipeline","params":[]}
{"jsonrpc":"2.0","id":1,"result":null}
```

## `admin_sequencerActive`

Returns whether the sequencer is currently active.

| Client | Method invocation                                   |
| ------ | --------------------------------------------------- |
| RPC    | `{"method": "admin_sequencerActive"}`               |

### Example

```js
// > {"jsonrpc":"2.0","id":1,"method":"admin_sequencerActive","params":[]}
{"jsonrpc":"2.0","id":1,"result":true}
```

## `admin_startSequencer`

Starts the sequencer at the supplied expected unsafe head. Conductor-managed nodes start
inactive and require a successful leader check before activation. An already active sequencer,
an unknown head, a mismatched hash, or a failed leader check returns an error.

The conductor must acknowledge each payload before the node imports or gossips it. A failed
commit leaves the sequencer active and retries the same build job without publishing a block.

### Parameters

- `expectedHead` (`Hash`): Required current unsafe head hash, normally returned by `admin_stopSequencer`.

### Example

```js
// > {"jsonrpc":"2.0","id":1,"method":"admin_startSequencer","params":["0x1234567890abcdef1234567890abcdef1234567890abcdef1234567890abcdef1234"]}
{"jsonrpc":"2.0","id":1,"result":null}
```

## `admin_stopSequencer`

Stops the sequencer and returns its settled unsafe head hash. A payload already acknowledged
by the conductor is settled before success while leadership and its engine context remain
valid. The response follows engine publication and gossip admission; abandoning the RPC
request does not cancel settlement. Calling Stop on an inactive sequencer returns an error.

| Client | Method invocation                                   |
| ------ | --------------------------------------------------- |
| RPC    | `{"method": "admin_stopSequencer"}`                 |

### Example

```js
// > {"jsonrpc":"2.0","id":1,"method":"admin_stopSequencer","params":[]}
{"jsonrpc":"2.0","id":1,"result":"0x1234567890abcdef1234567890abcdef1234567890abcdef1234567890abcdef"}
```

## `admin_setRecoverMode`

Sets the recovery mode for the sequencer.

| Client | Method invocation                                         |
| ------ | --------------------------------------------------------- |
| RPC    | `{"method": "admin_setRecoverMode", "params": [mode]}`    |

### Parameters

- `mode` (`bool`): Whether to enable recovery mode (true) or disable it (false)

### Example

```js
// > {"jsonrpc":"2.0","id":1,"method":"admin_setRecoverMode","params":[true]}
{"jsonrpc":"2.0","id":1,"result":null}
```

## `admin_overrideLeader`

Enables a process-local disaster recovery override. The node bypasses conductor leadership
checks and payload commits for the rest of this process, allowing sequencing after quorum
loss. Start still requires the current unsafe head hash. Restart the node to clear this override.

This method does not change the conductor service. While it lacks Raft leadership, its proxy
remains unavailable unless an operator separately calls `conductor_overrideLeader(true)`
on the conductor.

| Client | Method invocation                                   |
| ------ | --------------------------------------------------- |
| RPC    | `{"method": "admin_overrideLeader"}`                |

### Example

```js
// > {"jsonrpc":"2.0","id":1,"method":"admin_overrideLeader","params":[]}
{"jsonrpc":"2.0","id":1,"result":null}
```
