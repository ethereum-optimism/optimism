# op-reth

**OP Stack Execution Layer implementation built on [reth](../reth)**

op-reth extends reth with OP Stack specific functionality, providing an execution layer implementation for Optimism rollups.

## Documentation

- [Reth User Docs](https://reth.rs)
- [Reth Developer Docs](../reth/docs)
- [OP Stack Specs](https://specs.optimism.io/)

## Building

```sh
cargo build -p op-reth --release
```

## Running

op-reth follows the same CLI patterns as reth. See the [reth documentation](https://reth.rs) for detailed usage instructions.
