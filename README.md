## About the Superchain

The **Optimism Superchain** is a network of interoperable, permissionless chains that share security, a communication layer, and core infrastructure.  
It is designed to create a unified, scalable ecosystem where new chains can seamlessly integrate while contributing to the overall growth and decentralization of the Optimism Collective.

By standardizing critical components such as governance, security, and interoperability, the Superchain aims to minimize fragmentation and foster innovation across the Ethereum Layer 2 landscape.

> Learn more in the official [Superchain Documentation](https://community.optimism.io/docs/superchain/overview/).
