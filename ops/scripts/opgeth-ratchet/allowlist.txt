# the upstream release the cutover moves to (cutoverVersion in upstream.go).
#
# The monorepo is moving off op-geth to upstream go-ethereum, and every entry below blocks that
# cutover. Before adding one, check docs/ai/opgeth-decoupling.md for how to avoid the dependency
# (op-core/*, the op-service seams, op-reth). If there is no way around it yet, add the entry with
# a reason; reviewers will ask for one that holds up.
#
# Format: <package> | <what it needs from op-geth> | <reason>
# Entries no longer used are removed with `just opgeth-ratchet-update`.
#
# A reason starts with the issue tracking the entry's removal, so grepping for the issue number
# lists that issue's remaining entries, and the file's history shows its progress. Entries for
# #20266 are uses that only the cutover removes or rewrites: op-core transition code, op-geth
# differential tests, and "cutover edits" of APIs whose upstream form differs, often because
# upstream changed them after the release op-geth is based on. The reason of a cutover edit gives
# the upstream form to rewrite the use to.
